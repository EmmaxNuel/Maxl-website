# MAXL — Technology × Creativity

Official public website for MAXL. Built with Next.js (App Router, JavaScript),
Tailwind CSS, GSAP, Lenis, Framer Motion and React Three Fiber.

## Develop

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```

Set `NEXT_PUBLIC_SITE_URL` to the official domain (see `.env.example`).
Product URLs (e.g. the Manji install link) live in `data/products.js`.
